  each), with the display-blind case using the existing `spyOnDispatches` oracle rather than a

  coherent hole (F-1), not noise: every focused-button row in the suite uses `7`, `=` or `+`.

  I could construct here is covered or provably inert. Held `Escape`/`Delete` on the document remains
  undefined by OQ-4 and is idempotent — still correctly listed as "Not covered".

  (47 + 2), regression 25, with no pre-existing test edited, weakened, skipped or deleted
